# UH-60 黑鹰直升机 · 交互式 3D 解剖 (Black Hawk)

西科斯基 UH-60L"黑鹰"通用直升机的单文件 Three.js 交互演示,C4D 产品渲染风格。
按实机 1:1 比例建模(旋翼直径 16.36 m / 机身长 15.3 m / 高 5.13 m)。
系列作品:`turbofan-3d` · `single-cylinder-engine` · `four-cylinder-engine` ·
`turbojet-engine` · `f35` · `b2` · 本项目。

## 打开方式

- **直接双击 `index.html`**(Chrome / Edge),需联网加载 Three.js CDN;
- 或任意静态服务器后访问。

## 交互与演示

| 功能 | 说明 |
|---|---|
| 旋翼启动 | 发动机带转→惯性加速到 258 rpm;桨叶从停放下垂(-2.2°)过渡到飞行锥角(+2.8°),带旋翼模糊盘 |
| 滑动舱门 | 两侧舱门滑开露出机枪位门洞 |
| 后货桥 | 液压放平 72° |
| 舵面演示 | 全动平尾随动偏转 |
| 剖面切视 | 沿纵轴线切开看驾驶舱/货舱/传动布局 |
| 部件讲解 | 13 个部件中文卡片(弹性轴承旋翼/无轴承尾桨/ESSS/全动平尾…) |

## 结构对照

- **旋翼**:桨毂+自动倾斜器双环+变距拉杆×4+弹性轴承臂×4+4 叶(翼型放样、
  根弦 0.66→梢弦 0.44、扭转 13°→3°、桨尖 20° 后掠+白色识别条)
- **机体**:13 站位圆角超椭圆截面放样(驾驶舱收细、货舱宽体、尾梁收细)
- **动力**:2× T700 短舱 + 上翘 35° 排气筒(运转时排气口辉光)
- **ESSS 短翼** + 2× 200gal 副油箱(胶囊形)
- **尾组**:后掠垂尾(翼型放样)+ 顶部尾桨减速器罩 + 倾斜 20° 无轴承尾桨
  (交叉梁 4 叶)+ 全动平尾(下反)
- **起落架**:后掠主支柱×2 + 双侧拖曳臂 + 尾橇轮(不可收放)

拖动旋转 · 滚轮缩放 · 点击部件查看讲解;
快捷键:`R` 旋翼 · `D` 舱门 · `L` 标注。

`shots/` 内为验收截图(整机/运转/侧视/俯视/旋翼头)。

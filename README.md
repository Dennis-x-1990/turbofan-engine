# 涡喷发动机 · 交互式 3D 解剖 (Turbojet Engine)

带加力燃烧室的单转子涡喷发动机单文件三维交互演示,C4D 产品渲染风格。
系列作品:`turbofan-3d`(涡扇)· `single-cylinder-engine`(单缸机)·
`four-cylinder-engine`(四缸机)· 本项目。

## 打开方式

- **直接双击 `index.html`**(Chrome / Edge),需联网加载 Three.js CDN;
- 或任意静态服务器后访问。

## 核心演示

| 功能 | 说明 |
|---|---|
| 单转子 | 8 级压气机 + 2 级涡轮 + 空心轴同转(涡喷唯一转轴),与涡扇的双转子对照 |
| 8 级轴流压气机 | 转子/静子交替、通道收敛,总压比 ≈13 |
| 加力燃烧室 | V 形火焰稳定器 + 喷油环;开加力后二次喷油,推力 +50% |
| 可调尾喷口 | 16 组收敛-发散调节片随加力实时张开(四元数摆位) |
| 激波菱形 | 超音速尾流的激波胞沿尾焰滚动 |
| P-V 示功图 | 布雷顿循环;开加力显示再热虚线段 |
| 气流演示 | 进气→压气机(加旋/整流)→燃烧→涡轮→加力→尾喷 |
| 部件讲解 | 10 个部件中文卡片:激波锥、蹭套、加力油耗、空中点火…… |

## 交互

拖动旋转 / 滚轮缩放 / 右键平移;点击部件或标签查看讲解;
快捷键:`空格` 停车/起动 · `A` 加力 · `C` 剖面 · `L` 标注。

`shots/` 内为验收截图(整机 / 加力尾焰 / 透视 / 纵剖 / 迎面 / 爆炸)。

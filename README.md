# B-2 幽灵 隐身轰炸机 · 交互式 3D 解剖 (Spirit)

诺斯罗普·格鲁曼 B-2A"幽灵"隐身战略轰炸机的单文件 Three.js 交互演示,
C4D 产品渲染风格。参数按实机 1:1 比例(翼展 52.4 m / 长 21.0 m / 高 5.18 m)。
系列作品:`turbofan-3d` · `single-cylinder-engine` · `four-cylinder-engine` ·
`turbojet-engine` · `f35` · 本项目。

## 打开方式

- **直接双击 `index.html`**(Chrome / Edge),需联网加载 Three.js CDN;
- 或任意静态服务器后访问。

## 交互与演示

| 功能 | 说明 |
|---|---|
| 飞翼翼体 | 前缘 33° 后掠 + 双 W 锯齿尾缘,展向放样(21 个站位),翼体中段厚 2.3 m 容纳发动机 |
| 背部 S 弯进气道 | 每侧一个进气口、可见风扇面随油门旋转 |
| 二维窄缝排气 | 尾缘前上方窄缝 + 分隔导流片,油门联动微光 |
| 武器舱 | 前后双舱开启,旋转发射架挂 8 枚 JDAM 可见 |
| 起落架 | 前双轮 + 主四轮小车,收放动画 |
| 舵面演示 | 尾缘 10 块升降副翼偏转 |
| 剖面切视 | 沿纵轴线切开看乘员舱/弹舱/发动机布局 |
| 部件讲解 | 13 个部件中文卡片(雷达罩/座舱/S 弯进气/排气/弹舱/吸波蒙皮…) |

拖动旋转 · 滚轮缩放 · 点击部件查看讲解;快捷键:`B` 弹舱 · `G` 起落架 · `L` 标注。

`shots/` 内为验收截图(整机/俯视/弹舱/舵面演示)。

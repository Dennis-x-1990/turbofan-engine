# F-35 战斗机 · 交互式 3D 解剖 (Lightning II)

F-35A 隐身战斗机单文件三维交互演示,C4D 产品渲染风格。参照实机照片建模:
菱形机身截面、全身锯齿状蒙皮分缝线(程序化纹理)、DSI 进气道鼓包、
深金色全景座舱盖(后铰链可开,内含弹射座椅)、内置弹舱(4× AIM-120)、
外倾双垂尾、棕钛色锯齿喷口(可见涡轮盘)、加力尾焰。
系列作品:`turbofan-3d` · `single-cylinder-engine` · `four-cylinder-engine` · `turbojet-engine` · 本项目。

## 打开方式

- **直接双击 `index.html`**(Chrome / Edge),需联网加载 Three.js CDN;
- 或任意静态服务器后访问。

## 交互

| 功能 | 说明 |
|---|---|
| 武器舱 | 舱门开启,4 枚 AIM-120 下挂可见 |
| 起落架 | 前三点式收放(带撑杆/着陆灯细节) |
| 座舱盖 | 后铰链上翻,弹射座椅与飞行员可见 |
| 加力 | 尾焰拉长变亮,推力 125 → 190 kN |
| 舵面演示 | 平尾/垂尾偏转动画 |
| 剖面切视 | 沿纵轴线切开看舱段布局 |
| 部件讲解 | 12 个部件中文卡片(雷达罩/座舱盖/DSI/EOTS/弹舱/锯齿喷口…) |

拖动旋转 · 滚轮缩放 · 点击部件查看讲解;
快捷键:`B` 弹舱 · `G` 起落架 · `A` 加力 · `L` 标注。

`shots/` 内为验收截图。

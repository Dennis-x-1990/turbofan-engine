# 涡扇发动机 · 交互式 3D 解剖 (Turbofan Anatomy)

高涵道比双转子涡扇发动机的单文件三维交互演示,C4D 产品渲染风格(柔和摄影棚布光 + 浅灰渐变背景)。
全部几何体由代码程序化生成,无外部模型文件。

## 打开方式

- **直接双击 `index.html`**(Chrome / Edge),需联网加载 Three.js CDN;
- 或起本地服务:`python -m http.server 8000` 后访问 `http://localhost:8000`。

## 功能

| 功能 | 说明 |
|---|---|
| 3D 交互 | 拖动旋转 / 滚轮缩放 / 右键平移,点击任意部件查看中文讲解(16 个部件) |
| 视角 | 整机 · 正面 · 侧面 · 尾部,平滑飞行切换 |
| 剖面切视 | 切除朝向镜头的 1/4 楔块,经典 cutaway 视角 |
| 透视外壳 | 短舱与核心机机匣半透明,直视全部内部转子 |
| 爆炸视图 | 滑块 0–100%,短舱向上掀起、模块沿轴向展开,镜头自动拉远 |
| 气流演示 | 内涵/外涵流线粒子 + 燃油雾化 + 燃烧室辉光 + 尾焰(开启时自动切入剖面) |
| 运行原理 | 布雷顿循环沿程总温/总压图表,随油门实时变化,五阶段循环高亮 |
| 双转子 | N1(风扇+增压级+低压涡轮)与 N2(高压压气机+高压涡轮)反转,油门联动转速/EGT/推力仪表 |
| 快捷键 | `空格` 启动/停车 · `C` 剖面 · `L` 标注 |

## 结构对应

进气短舱 → 22 片宽弦风扇 → 出口导流叶 → 3 级增压级 → 7 级高压压气机 →
环形燃烧室(16 喷嘴)→ 单级高压涡轮 → 4 级低压涡轮 → 尾锥/喷管;
附件齿轮箱与安装节、双转子轴系均可独立查看。

`shots/` 内为验收截图(整机 / 剖面气流 / 爆炸 / 正面)。

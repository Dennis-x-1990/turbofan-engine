直列四缸 2.0L DOHC 16V 汽油发动机的单文件三维交互演示,C4D 产品渲染风格。
全部几何体程序化生成,无外部模型文件。系列作品:
`D:\CODING\turbofan-3d`(涡扇)· `D:\CODING\single-cylinder-engine`(单缸机)· 本项目。

## 打开方式

- **直接双击 `index.html`**(Chrome / Edge),需联网加载 Three.js CDN;
- 或任意静态服务器后访问。

## 结构

缸体(4 缸孔+水冷)→ 缸垫 → 缸盖(4 燃烧室 / 16 气门 / 双凸轮 / 4 火花塞线圈)→
正时带(曲轴 → 进、排凸轮 2:1)→ 活塞×4(3 环+浮动销)→ 连杆×4 →
平面曲轴(5 主轴颈)→ 飞轮环齿 / 减振皮带轮;
进气歧管谐振腔+节气门+油轨 4 喷油器;排气 4-1 集管;油底壳+主轴承盖 ×5。

`shots/` 内为验收截图(整机剖面 / 纵剖 / 透视 / 爆炸 / 正时面 / 气流 / 发火验证)。

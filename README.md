# 单缸汽油发动机 · 交互式 3D 解剖 (Single-Cylinder Engine)

单缸四冲程顶置凸轮(OHC)汽油发动机的单文件三维交互演示,C4D 产品渲染风格
(柔和摄影棚布光 + 浅灰渐变背景)。全部几何体程序化生成,无外部模型文件。
与 `D:\CODING\turbofan-3d`(涡扇发动机)同属一个系列。

## 打开方式

- **直接双击 `index.html`**(Chrome / Edge),需联网加载 Three.js CDN;
- 或任意静态服务器:`python -m http.server 8000` → `http://localhost:8000`。

## 核心演示

| 功能 | 说明 |
|---|---|
| 真实运动学 | 活塞位移 = R·cosθ+√(L²−R²sin²θ),连杆摆角、凸轮半转速、气门升程曲线(含气门重叠角)、点火提前角 10° BTDC |
| 剖面切视 | 沿气缸轴线切除朝向镜头的一半,看曲柄连杆 + 配气机构全貌 |
| 透视外壳 | 散热片缸体/缸盖/曲轴箱半透明,内部机构一目了然 |
| 爆炸视图 | 缸盖、缸垫、缸体、活塞、连杆、曲轴、飞轮、正时链、进排气分层展开 |
| 气流演示 | 进气蓝流 → 喷油器锥形喷雾 → 缸内混合 → 排气橙流(开启时自动切入剖面) |
| P-V 示功图 | 四冲程奥托循环指示图,工作点实时追踪,峰值缸压 ≈58 bar |
| 慢放 | ×0.001~×0.25 变速,把 8000 rpm 的循环放到肉眼可读 |
| 部件讲解 | 18 个部件中文卡片:活塞环、飞轮磁电机、正时链 2:1、充钠排气门…… |

## 交互

拖动旋转 / 滚轮缩放 / 右键平移;点击部件或标签查看讲解;
快捷键:`空格` 起动/熄火 · `C` 剖面 · `L` 标注。

## 结构

散热片缸体 → 缸垫 → 缸盖(楔形燃烧室/双气门/弹簧/挺柱)→ 顶置凸轮轴 ←
正时链(曲轴 17 齿 → 凸轮 34 齿)→ 活塞(3 环+浮动销)→ 工字连杆 →
配重曲轴 → 飞轮风扇;节气门+喷油器在进气侧,排气歧管在排气侧,油底壳飞溅润滑。

`shots/` 内为验收截图(整机剖面 / 燃烧做功 / 透视 / 爆炸 / 正时面 / 气流)。
